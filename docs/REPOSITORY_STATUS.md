# LoopForge Repository Status

This repository contains the production-oriented LoopForge Pro v2 source tree.

## Repository baseline

- Expo / React Native application
- Native audio graph via `react-native-audio-api`
- Deterministic generated application/audio assets
- CI checks for source integrity, TypeScript, linting and tests
- Android debug APK workflow
- Dependabot dependency maintenance
- CODEOWNERS, issue templates and pull-request template
- Security and contribution policies
- No local credentials or `.env` secrets committed
